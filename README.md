# Sales Data Analysis Project

## Overview
This project analyzes sales data using Python and Power BI to identify sales trends, profit performance, and business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

## Project Features
- Data Cleaning
- Sales Analysis
- Profit Analysis
- Category-wise Sales
- Region-wise Sales
- Top 10 Products Analysis
- Interactive Power BI Dashboard

## Files
- Sales_Analysis.ipynb
- cleaned_sales_data.csv
- Sales_Dashboard.pbix
